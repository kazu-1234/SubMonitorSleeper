# SubMonitorSleeper

デュアルモニター環境で、サブモニターを使っていないときだけ消灯し、使い始めたら点灯する Windows 常駐アプリです（WinUI 3 / .NET 8）。
消灯・点灯は DDC/CI の VCP コード `0xD6`（Power Mode）で行い、Windows の画面構成（拡張表示）は変更しません。

## 機能（v0.4.0）

- **自動消灯**: サブ上にアプリのウィンドウが 1 つもなく、カーソルもサブ上にない状態が、Windows の「画面をオフにする」時間だけ続くと消灯（「なし」なら自動消灯しない。AC / バッテリーの値を使い分け、設定変更にも追従）
- **自動点灯**: 消灯中にカーソルがサブへ入る、または自動で消した後にサブ上へウィンドウが現れると点灯
- **ホットキー**: 押すたびに消灯 / 点灯を切り替え（既定 Ctrl+Alt+M、設定で変更可）
- **タスクトレイ**: 「今すぐ消す」「今すぐ点ける」「一時停止」「設定を開く」「終了」
- **設定画面**: 対象モニター（自動 / 接続中の一覧）、消灯時の値（4 スタンバイ / 5 電源オフ）、ホットキー、待ち時間の表示、テスト消灯、自動起動（ログオンタスク / スタートアップ）、テーマ
- **安全対策**: 手動点灯後 1 分は自動消灯しない。終了時・未処理例外時・スリープ復帰時・ロック解除時・次回起動時（強制終了後）に点灯へ戻す。D6 の送信に失敗したらトレイ通知して自動消灯を一時停止。多重起動防止

PC 全体を放置したときの画面オフ・スリープは Windows の動作に任せます。

## ビルド

- Visual Studio 2022 / 2026、x64
- 共通基盤 `WinUiShared` を **`..\WinUiAppTemplate\Shared`** から参照しています。同じ親フォルダに `WinUiAppTemplate` を置いてください。

## 対象モニターの条件

- モニター本体の設定で DDC/CI が有効になっていること
- D6 による電源制御に対応していること（機種によっては 5 で DDC も止まり、D6 = 1 で戻せないことがあります）
