# SubMonitorSleeper

デュアルモニター環境で、サブモニターを使っていないときだけ消灯し、使い始めたら点灯する Windows 常駐アプリです（WinUI 3 / .NET 8）。
消灯・点灯は DDC/CI の VCP コード `0xD6`（Power Mode）で行い、Windows の画面構成（拡張表示）は変更しません。

## 現在の版（v0.1.0）

- タスクトレイ常駐（「今すぐ消す」「今すぐ点ける」「設定を開く」「終了」）
- 設定画面の「テスト消灯」（消灯して 5 秒後に自動で点灯）
- 対象モニターは「Windows でメインに設定されていないモニター」を自動で選択
- 消灯値は D6 = 4（スタンバイ）。`%AppData%\SubMonitorSleeper\settings.json` の `PowerOffValue` を 5 にすると電源オフ
- 終了時・未処理例外時・スリープ復帰時・ロック解除時・次回起動時（強制終了後）に点灯へ戻す
- D6 の送信に失敗したらトレイ通知

自動判定（ウィンドウの有無・カーソル位置・Windows の画面オフ時間）、カーソル進入やホットキーによる点灯は以降の版で追加します。

## ビルド

- Visual Studio 2022 / 2026、x64
- 共通基盤 `WinUiShared` を **`..\WinUiAppTemplate\Shared`** から参照しています。同じ親フォルダに `WinUiAppTemplate` を置いてください。

## 対象モニターの条件

- モニター本体の設定で DDC/CI が有効になっていること
- D6 による電源制御に対応していること（機種によっては 5 で DDC も止まり、D6 = 1 で戻せないことがあります）
